Introductory Python course focused on data analysis, organized by IAS-CSIC (Córdoba). 
Held from March 31 to April 4, 2025.

## Contents
- Python fundamentals and development environments (Jupyter, JupyterLab)
- Basic structures: variables, functions, loops, conditionals and classes
- File and directory management with the `os` module
- Data analysis with NumPy, Pandas and SciPy
- Data visualization with Matplotlib, Seaborn and Plotly
- Best practices in code structuring and documentation

## Duration
22 h
