Intermediate Python course focused on agronomic and geospatial data analysis, 
organized by IAS-CSIC (Córdoba). Held from September 22 to 26, 2025.

## Contents
- Review of Python fundamentals at intermediate level
- Management of coding environments with Anaconda
- Agronomic data processing and analysis
- Geospatial libraries (GeoPandas, Rasterio, GDAL)
- Coordinate systems, GIS and geographic projections
- Advanced spatial data visualization
- Image analysis techniques in agricultural contexts
- Introduction to statistical analysis with Python

## Duration
22 h
